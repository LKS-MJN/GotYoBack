# Web Research

When you need current information:

1. Use the built-in `websearch` tool for general queries
2. Use `webfetch` to pull documentation from official sources
3. For library docs, prefer fetching from the library's own docs site or GitHub README
4. Cache results by mentioning what you found — don't refetch the same page in the same session
