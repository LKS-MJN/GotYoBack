# SEO Audit Skill

Perform comprehensive SEO audits and optimization for the Mannat Overseas Consultants website.

## Audit Checklist

### Technical SEO
1. Meta tags: title (under 60 chars), meta description (150-160 chars)
2. Heading hierarchy: one H1 per page, proper H2/H3 structure
3. Image alt text on all images
4. Page speed and Core Web Vitals
5. Mobile responsiveness
6. Structured data / JSON-LD schema
7. No broken links (internal or external)
8. No em-dashes (use regular hyphens) - project rule

### On-Page SEO
1. Keyword in title tag, H1, first paragraph
2. URL slug optimization
3. Internal linking to related pages
4. External links to authoritative sources
5. Content quality and relevance
6. FAQ sections for featured snippets

### Content Optimization
1. Check for thin content
2. Ensure unique value proposition per page
3. Verify CTAs are clear and action-oriented
4. Check brand consistency (Mannat Overseas Consultants)

## Pages to Audit

- `/` - Homepage
- `/about` - About Us
- `/study-abroad` - Study Abroad
- `/immigration` - PR & Visas
- `/success-stories` - Success Stories
- `/contact` - Contact Us

## Tools

- Use webfetch to check page content and meta tags
- Verify structured data rendering
- Check internal link structure
