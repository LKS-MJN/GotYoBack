# GotYoBack Knowledge Base

Structured, source-aware knowledge base for the GotYoBack interactive learning platform.

## Structure

- `curriculum/` — Curriculum map and domain definitions.
- `lessons/` — Structured lesson JSON files by domain.
- `quizzes/` — Question banks by domain.
- `experiments/` — Interactive simulation specifications.
- `projects/` — Guided project definitions.
- `sources/` — Source inventory and attribution.
- `review-records/` — Technical review and quality tracking.

## Rules

- All content is original.
- External sources are credited and linked.
- No DSA, sorting, or generic programming material.
- Every item records its assumptions, review status, and intended learning outcome.
- Technical claims are verified against official documentation where possible.
